# 🏭 Website Công Ty TNHH Bao Bì Ánh Dương

🌐 **Website:** https://anhduongparking.io.vn

## 📋 Giới Thiệu Dự Án

Website chuyên nghiệp cho **Công ty TNHH Bao Bì Ánh Dương** - doanh nghiệp sản xuất bao bì với 20 năm kinh nghiệm trong ngành. Website được thiết kế hiện đại, tối ưu SEO và responsive trên mọi thiết bị.

### 🎯 Mục Tiêu Website

- Giới thiệu công ty và 20 năm kinh nghiệm trong ngành bao bì
- Trưng bày sản phẩm, mẫu mã và thông tin kỹ thuật
- Cung cấp bảng giá tham khảo cho khách hàng
- Cho phép khách hàng đặt hàng và yêu cầu báo giá trực tuyến
- Tối ưu cho SEO, tải nhanh, dễ sử dụng trên mobile

## 🚀 Hướng Dẫn Sử Dụng

### Chạy Local
1. Clone hoặc download project
2. Mở file `index.html` trong trình duyệt
3. Hoặc sử dụng Live Server (VSCode extension)

### Deploy

Website đã được cấu hình sẵn cho tên miền: **anhduongparking.io.vn**

#### Deploy lên GitHub Pages:
1. Push code lên GitHub repository
2. Vào Settings → Pages
3. Chọn branch `main` hoặc `master`
4. Website sẽ có tại: `https://username.github.io/repository-name`

#### Deploy lên Netlify (Khuyến nghị):
1. Đăng ký tài khoản tại https://www.netlify.com
2. Kéo thả folder website vào Netlify
3. Vào Domain settings → Add custom domain
4. Nhập: `anhduongparking.io.vn`
5. Làm theo hướng dẫn cấu hình DNS

#### Deploy lên Vercel:
1. Import project từ GitHub
2. Deploy tự động
3. Thêm custom domain `anhduongparking.io.vn`

#### Deploy lên Hosting có FTP:
1. Upload tất cả files qua FTP
2. Đảm bảo `index.html` ở thư mục gốc
3. Xem chi tiết trong file `HUONG_DAN_DEPLOY.md`

**Xem hướng dẫn chi tiết:** [HUONG_DAN_DEPLOY.md](./HUONG_DAN_DEPLOY.md)

## 🔧 Customization Guide

### Thay Đổi Màu Sắc
Chỉnh sửa CSS variables trong `css/style.css`:
```css
:root {
    --primary-yellow: #FFB800;  /* Màu vàng chính */
```

## 🐛 Known Issues & Solutions

### Issue 1: Form Submission
**Vấn đề**: Form hiện chỉ có validation, chưa gửi data thực tế  
**Giải pháp**: Cần tích hợp với backend API hoặc email service

### Issue 2: File Upload
**Vấn đề**: File upload chỉ preview, không upload lên server  
**Giải pháp**: Cần server-side endpoint để xử lý file

### Issue 3: Images Loading
**Vấn đề**: Một số ảnh placeholder từ Unsplash có thể load chậm  
**Giải pháp**: Thay bằng ảnh local hoặc CDN tối ưu
